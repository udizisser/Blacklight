# Blacklight

A very simple reverb from UDI DSP: Clearlight's engine in a closed box, with two controls, SIZE and DECAY, plus IN,
OUT and MIX. Built as a Clearlight edition (the code lives in Clearlight's repo). This repo holds the design.

Start with [docs/design-brief.md](docs/design-brief.md) and [docs/session-handover.md](docs/session-handover.md).

Status: Phase 0 rendered (the owner's listening open), Phase 1 built in Clearlight's repo on branch `blacklight-phase0`
(2026-10-25: every gate green, the VST3 installed on the desktop, nothing heard, nothing on the Mac). Beta until UDI DSP
releases it.
